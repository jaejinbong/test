📝 랭킹 데이터

📌 사용 방법

  1. 게임을 플레이한 브라우저에서 이 페이지를 엽니다
  2. "로컬 랭킹 불러오기" 버튼을 클릭하여 로컬 데이터를 확인합니다
  3. "글로벌 랭킹 불러오기" 버튼으로 기존 서버 데이터를 가져옵니다
  4. "랭킹 병합하기"로 두 데이터를 합칩니다
  5. "JSON 파일 다운로드"로 rankings.json 파일을 받습니다
  6. 다운로드한 파일을 GitHub 리포지토리에 커밋합니다
